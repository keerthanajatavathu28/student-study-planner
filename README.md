# 📚 Student Study Planner

A simple Python-based study planner that helps students organize their study tasks, set deadlines, manage priorities, and track completed work.

## ✨ Features

- ➕ Add study tasks
- 📋 View all tasks
- 📅 Set due dates
- ⭐ Set task priorities
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Search for tasks
- 📊 View study dashboard
- ⏰ Automatically identify overdue and due-today tasks
- 💾 Save tasks permanently using JSON

## 🛠️ Technologies Used

- Python
- JSON
- VS Code
- Git & GitHub
